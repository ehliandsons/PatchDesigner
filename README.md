# PatchDesigner — User & Admin Guide  
### Designed & Developed by **Andrew Ehli**

---

## 📌 Overview  
PatchDesigner is a custom patch‑building experience for Shopify stores.  
It allows customers to design their own patch directly on the product page, and gives store owners a dedicated Admin Dashboard to view, edit, and reproduce those designs for production.

This guide explains:

- How customers use PatchDesigner on your storefront  
- How store owners access the PatchDesigner Admin  
- How orders store patch configuration data  
- How to load and edit customer designs in the Admin Dashboard  

---

# 🛒 1. Customer Experience (Shopify Storefront)

## 🎨 Designing a Patch  
On any product where PatchDesigner is enabled, customers will see the **Patch Previewer** block.

Customers can:

- Upload a patch image  
- Add text zones  
- Drag text around the patch  
- Change fonts, colors, and sizes  
- Preview the final design in real time
